# Abbildungen

[← Kursübersicht](../README.md)

Abbildungen liegen passend zu den Modulen in `00-einstieg` bis `27-verifikation-dokumentation`.

## Qualitätsregeln

- Elektrische Schaltungen verwenden bevorzugt genormte IEC-Schaltzeichen: rechteckiges Widerstandssymbol, eindeutige Spannungsquellen, Kondensator-/Spulen-/Diodensymbole, Verbindungspunkte und Bezugszeichen.
- Jeder Strompfeil, Spannungspfeil, Messpunkt und Bezug ist eindeutig beschriftet.
- Ein Schema zeigt elektrische Funktion; bildhafte Bauteilzeichnungen werden nur ergänzend genutzt.
- Zeitdiagramme und Kennlinien besitzen Achsen, Einheiten und Betriebsbedingungen.
- SVG wird für reproduzierbare Schaltbilder und Diagramme bevorzugt; jede Einbindung benötigt aussagekräftigen Alt-Text.
- Jede Abbildung beantwortet eine konkrete fachliche Frage und wird vor Freigabe technisch geprüft.
