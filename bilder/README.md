# Abbildungen

[← Kursübersicht](../README.md)

Bilder liegen modulweise in `bilder/00-…` bis `bilder/27-…`. Bevorzugtes Format ist SVG, weil Schaltbilder und Signaldiagramme scharf, diffbar und barriereärmer bleiben. Jede Abbildung benötigt einen aussagekräftigen Dateinamen, Alt-Text im einbindenden Markdown und eine fachliche Gegenprüfung.

Pilotabbildungen für Module 00–02 werden in Phase 2 ergänzt. Für spätere Module sind die Verzeichnisse bereits vorbereitet.
