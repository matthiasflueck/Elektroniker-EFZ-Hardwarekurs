# Lösungen – Modul 08

[← Übungen](../uebungen/modul-08.md) · [Lösungsübersicht](README.md)

1. Rechnerisch R = 1/(2π·1 kHz·100 nF) = 1,59 kΩ. E24: 1,6 kΩ, daraus fG ≈ 995 Hz.
2. Bei fG ist |H| = 0,707 beziehungsweise −3,01 dB. Bei 10fG ist |H| ≈ 0,0995 beziehungsweise ungefähr −20,04 dB.
3. Der Serienkondensator reagiert wie ein beweglicher Koppler: Eine Änderung erscheint sofort, ein dauerhafter Zustand klingt über R ab. Mathematisch fällt Uout exponentiell gegen den Biaswert.
4. `fG = 1/(2π·470 µs) ≈ 338,6 Hz`; 5τ = 2,35 ms.
5. 0,5 → −6,02 dB; 0,1 → −20 dB; 2 → +6,02 dB.
6. `fG = 150/(2π·0,012) ≈ 1,99 kHz`; `τ = 0,012/150 = 80 µs`.
7. `f0 = 1/(2πsqrt(4,7 mH·220 nF)) ≈ 4,95 kHz`.
8. B = 0,8 kHz und Q = 10. Quellenwiderstand, Tastkopf/Voltmeter und Lastwiderstand dämpfen den Kreis; zusätzlich wirken DCR und ESR der Bauteile.
