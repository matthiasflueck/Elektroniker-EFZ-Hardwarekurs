# Handlungskompetenzen

[← Bildungsplan](README.md) · [Kompetenzmatrix](kompetenzmatrix.md)

| Code | Status | Kurzbezeichnung |
|---|---|---|
| `a1` | Pflicht | Anforderungen und Bedürfnisse an Hard- oder Softwareproblemstellungen erfassen und interpretieren |
| `a2` | Pflicht | Ideen, Konzepte und Lösungen für Hard- oder Softwareproblemstellungen entwickeln |
| `a3` | Pflicht | Machbarkeit von Ideen oder Aufträgen für Hard- oder Softwarelösungen abklären |
| `b1` | Pflicht | Elektronische Schaltungen dimensionieren und das Schema entwickeln |
| `b2` | Pflicht | Layout für Leiterplatten entwickeln und Fertigungsunterlagen erstellen |
| `b3` | Pflicht | Leiterplatten und Baugruppen fertigen |
| `b4` | Pflicht | Schaltungen in Betrieb nehmen, ausmessen und Fehler beheben |
| `b5` | Pflicht | Anforderungen an die Schaltung überprüfen |
| `b6` | Wahlpflicht | Elektronische Baugruppen in Betrieb nehmen |
| `b7` | Wahlpflicht | Frontplatten, Gehäuse oder einfache mechanische Bauteile bearbeiten oder fertigen |
| `c1` | Pflicht | Mikrocontroller-Programme entwickeln |
| `c2` | Pflicht | Anforderungen an die Software überprüfen |
| `c3` | Wahlpflicht | Intelligente Komponenten und Dienste in ein Netz oder eine Cloud einbinden |
| `c4` | Wahlpflicht | Applikationen zum Ansteuern von Hardware entwickeln |
| `c5` | Wahlpflicht | Logikschaltungen in komplexen Logikbausteinen programmieren |
| `d1` | Pflicht | Projektorientierte Aufträge im Elektronikbereich planen |
| `d2` | Pflicht | Verläufe projektorientierter Aufträge kontrollieren |
| `d3` | Pflicht | Ergebnisse projektorientierter Aufträge auswerten |
| `d4` | Wahlpflicht | Kundinnen und Kunden im Umgang mit Produkten ausbilden |
| `d5` | Wahlpflicht | Serienfertigungsaufträge in der Elektronik abwickeln |
| `d6` | Wahlpflicht | Produktions- oder Arbeitsmittel mit elektronischen Bauteilen instand halten |
| `d7` | Wahlpflicht | Prozessdaten automatisierter Anlagen überwachen und Massnahmen einleiten |
| `d8` | Wahlpflicht | Funktionen von Geräten prüfen |
| `d9` | Wahlpflicht | Technische Systeme mit elektronischen Komponenten aufbauen, konfigurieren und in Betrieb nehmen |

Pflicht für alle Lernenden sind gemäss Bildungsplan `a1–a3`, `b1–b5`, `c1–c2` und `d1–d3`. Aus `b6–b7`, `c3–c5` und `d4–d9` sind zwei Handlungskompetenzen verbindlich aufzubauen. Die Kurzbezeichnungen dienen der Navigation; verbindlich sind die vollständigen Arbeitssituationen und Leistungskriterien im offiziellen Bildungsplan.
